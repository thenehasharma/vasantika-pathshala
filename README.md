# Vāsantikā Pathshala

Website of Vāsantikā Pathshala, a school in Vraja giving children spiritual and material education together.

## Files

| Path | What it is |
| --- | --- |
| `index.html` | The whole page |
| `css/style.css` | Colours, fonts and layout |
| `js/main.js` | Daily schedule, donation picker, mobile menu |
| `images/` | Favicon, share image, and the place for school photos |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

## Hosting on GitHub Pages

1. Push these files to the root of a GitHub repository.
2. On GitHub, open the repository's **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to "Deploy from a branch", choose the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two the site is live at `https://<username>.github.io/<repository>/`. A repository named exactly `<username>.github.io` is served at `https://<username>.github.io/`.
